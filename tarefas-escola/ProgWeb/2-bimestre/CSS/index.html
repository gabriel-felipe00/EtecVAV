Propriedade

É a característica visual que você quer modificar.

Valor

É a configuração ou o estado que você vai aplicar à propriedade

Exemplos: color (cor do texto), font-size (tamanho da fonte), background-color (cor de fundo)

Principais funções e vantagens do CSS:

Separação de responsabilidades:

Evita que a estrutura do documento se misture com a parte estética, facilitando alterações futuras

Responsividade:

h3>Permite que o site se adapte automaticamente a telas de diferentes tamanhos, como computadores e celulares.

Padronização:

Um único arquivo CSS pode controlar o visual de dezenas de páginas de um site ao mesmo tempo
