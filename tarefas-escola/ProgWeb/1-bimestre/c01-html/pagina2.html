O HTML (HyperText Markup Language) foi criado por Tim Berners-Lee entre 1989 e 1990 no CERN (Organização Europeia para a Pesquisa Nuclear). O objetivo era permitir que pesquisadores compartilhassem documentos científicos facilmente, criando uma linguagem baseada em hipertexto para conectar informações. A primeira versão pública apareceu em 1991.

1989-1990: Tim Berners-Lee desenvolve o conceito de HTML, HTTP e o primeiro navegador.

1991: Primeira menção pública dos "tags HTML".

HTML 2.0 (1995): Primeira versão oficial e padronizada.

HTML 4.01 (1999): Tornou-se um padrão muito estável e amplamente utilizado por anos.

HTML5 (2014): A versão moderna, introduzida para suportar aplicações web ricas, multimídia (, ) e melhor semântica (, ). A criação do HTML foi fundamental para a popularização da World Wide Web, permitindo estruturar conteúdo de forma simples, organizada e acessível em qualquer navegador
